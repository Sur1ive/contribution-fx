Setup · about two minutes

Put it on your profile

Everything happens in your profile repository, <your-username>/<your-username>, the one whose README shows on your GitHub page.

  1. Add the workflow

    Create .github/workflows/contribution-fx.yml with this content. The two outputs lines follow your playground choices.

    Create this file on GitHub →
    contribution-fx.yml

  2. Run it once

    Open the Actions tab, choose contribution-fx and press Run workflow. It publishes the SVGs to an output branch, then refreshes them every day at midnight UTC.

    Open the Actions tab →

  3. Paste into README.md

    The <picture> tag shows the dark version to visitors who use GitHub in dark mode.

    Edit your README →
    README.md
